# 🤖 AI Data Analyst Agent — Frontend

React PWA frontend for the AI Data Analyst Agent. Deployed on Cloudflare Pages.

## Live App
👉 **[ai-agent-frontend-2ij.pages.dev](https://ai-agent-frontend-2ij.pages.dev)**

## Backend Repo
👉 **[github.com/lux-lator555/ai-data-analyst-agent](https://github.com/lux-lator555/ai-data-analyst-agent)**

## Tech Stack
- React (PWA)
- Cloudflare Pages (hosting)
- Plotly (interactive charts)
- react-markdown (formatted output)
- jsPDF + html2canvas (PDF export)

## Features
- Auto-detect dataset type on upload
- Suggested prompt buttons
- Walking robot 🤖 progress indicator
- Model comparison table
- Confidence assessment display
- Data quality report
- Interactive charts
- Business recommendations with copy to clipboard
- PDF export
- Follow-up chat interface
- Analysis history within session

## Local Development
```bash
npm install
npm start
```

## Deployment
Auto-deploys to Cloudflare Pages on push to `main`.
